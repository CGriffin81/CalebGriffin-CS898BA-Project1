# Project Rules

This is a short academic CNN image classification project.

## Engineering Rules

- Inspect existing code before modifying.
- Make minimal changes.
- Preserve existing structure and naming conventions.
- Avoid unnecessary dependencies.
- Do not rewrite working code.
- Do not over-engineer.

## Communication Rules

- Be concise.
- Do not explain code unless requested.
- Do not summarize files unless requested.
- Do not repeat requirements already provided.
- Ask questions only when blocked.
- Report completed work, files changed, and next action.

## ML Rules

- Prevent data leakage.
- Keep test data untouched until final evaluation.
- Use validation data for hyperparameter selection.
- Save reproducible results.
